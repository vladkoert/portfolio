Kæshy

A visual identity for Kæshy, a streetwear brand — a bold wordmark built around the Æ ligature, Klein blue as the signature colour, and a set of woven labels and hang tags for the first collection.

Kæshy is built around a single idea: a wordmark bold enough to carry the brand on its own, with the Æ ligature giving it a shape no other streetwear label has.

Klein blue runs through everything — the logo, the labels, the tags — with black, dark grey and off-white as the only supporting colours.
